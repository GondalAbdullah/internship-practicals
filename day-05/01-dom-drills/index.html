    Frequently asked

    The HTML file is text sent by the server. The DOM is the live tree of objects the browser builds from it, which JavaScript can change without touching the file.

    One listener on a stable parent handles clicks for every child, including children added later, because events bubble up the tree.

    innerHTML parses its input as markup, so user-supplied text can execute script (XSS). textContent always treats the value as plain text.
