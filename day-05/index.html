Day 5: JavaScript in the browser

DOM, events and asynchronous code: reading and changing the page, responding to users, and handling data that arrives later.

  • Task 1: DOM drills

    Restyle every second table row, build a list from data, remove cards through event delegation, and hand-built tabs and accordion.

  • Task 2: Interactive task manager

    Add, edit, complete, delete and filter. State persisted to localStorage, inline validation, and one render function derived from state.

  • Task 3: Live data application

    A public API with loading, empty, success and error states, retry, debounced search, cancelled stale requests, pagination and a detail view.
